# SubFa: زیرنویس‌ساز فارسی

**یک فایل بفرست، یا لینک ویدیو را بچسبان، زیرنویس فارسی تحویل بگیر.**

SubFa روی کامپیوتر خودت از یک فایل ویدیویی یا صوتی زیرنویس می‌سازد:
فایل زیرنویس به زبان مقصد (پیش‌فرض فارسی)، فایل زیرنویس دوزبانه،
متن کامل ویدیو، و برای ویدیوها یک نسخه با زیرنویس چسبیده روی تصویر.
بدون ساخت حساب، بدون آپلود فایل پیش غریبه‌ها، بدون هزینه به‌ازای دقیقه.

نسخه انگلیسی: [README.md](README.md)

## چه کار می‌کند؟

- **سه راه استفاده:** بات تلگرام، یک صفحه وب ساده، و خط فرمان (CLI).
- **دو نوع ورودی:** آپلود فایل، یا چسباندن لینک صفحه ویدیو (یوتیوب و
  همه سایت‌هایی که yt-dlp پشتیبانی می‌کند).
- **مسیر سریع زیرنویس آماده:** اگر خود ویدیو زیرنویس یا کپشن منتشرشده
  به زبان اصلی داشته باشد، SubFa از همان استفاده می‌کند و اصلا سراغ
  تشخیص گفتار نمی‌رود. اگر زیرنویس نباشد یا قابل استفاده نباشد،
  خودکار با Whisper پیاده‌سازی می‌کند. نتیجه همیشه می‌گوید کدام مسیر
  استفاده شده است.
- **پیاده‌سازی گفتار محلی با موتور مخصوص هر زبان.** ویسپر معمولی
  برای فارسی ضعیف است (خطای کلمه‌ای منتشرشده بین ۲۰ تا ۵۶ درصد)،
  برای همین صدای فارسی به یک مدل ویسپر فاین‌تیون‌شده برای فارسی
  می‌رسد (nezamisafa/whisper-persian-v4، بهترین مدل فارسی در
  بنچمارک PESTE). بقیه زبان‌ها با faster-whisper و مدل
  large-v3-turbo و تنظیمات ضدتوهم‌زایی پیاده می‌شوند. انتخاب
  موتور خودکار است؛ سند کامل تصمیم در
  [docs/ASR.md](docs/ASR.md) آمده است.
- **ترجمه آفلاین** با Argos Translate؛ بعد از یک بار دانلود مدل،
  ترجمه کاملا بدون اینترنت کار می‌کند.
- **واژه‌نامه‌ها** اصطلاحات تخصصی را ثابت نگه می‌دارند: برای هر موضوع
  یک فایل JSON. واژه‌نامه‌های آماده: عمومی، برنامه‌نویسی، بازی.
- **خروجی‌ها:** فایل `name.fa.srt`، فایل `name.bilingual.srt`، فایل
  `name.transcript.txt` و برای ویدیوها `name.subbed.mp4`.

## کیفیت، جدی گرفته شده

زیرنویس تجربه خواندن است و بیشتر ابزارها همین جا خراب می‌کنند. در
SubFa این‌ها قانون‌اند و تست دارند:

- **ساخت زیرنویس:** حداکثر 42 نویسه در هر خط و 2 خط در هر زیرنویس،
  سرعت خواندن حداکثر 20 نویسه در ثانیه، شکستن زیرنویس اول سر جمله و
  بعد سر بند، و ادغام زیرنویس‌های کوتاه‌تر از یک ثانیه.
- **پاک‌سازی متن فارسی:** تبدیل ی و ک عربی به فارسی، نیم‌فاصله در
  الگوهای رایج (می‌شود، کتاب‌ها، بزرگ‌تر)، اصلاح فاصله‌گذاری علائم و
  گیومه فارسی، و یکدست‌سازی ارقام (تنظیم `SUBFA_DIGITS`).
- **ترجمه با بافت متن:** زیرنویس‌ها در پنجره‌های لغزان 10تایی با 2
  زیرنویس بافت در هر طرف ترجمه می‌شوند تا ضمیرها و جمله‌های نصف‌شده
  درست بمانند. واژه‌نامه بعد از ترجمه اعمال می‌شود.
- **سبک‌های چسباندن زیرنویس:** `cinema` برای ویدیوی معمولی، `reels`
  برای ویدیوی عمودی 9:16، و `learning` برای دوزبانه آموزشی. از خط
  فرمان با `--style`، در بات با دکمه، و در وب با انتخاب در فرم.
- **ویرایشگر زیرنویس در وب:** بعد از اتمام کار، از صفحه نتیجه وارد
  ویرایشگر شو، متن و زمان را اصلاح کن، ذخیره کن و بدون پیاده‌سازی
  دوباره، ویدیو را از نو بساز یا فایل را دانلود کن.
- **گزارش کیفیت هر کار:** تعداد زیرنویس، درصد زیرنویس‌های سریع‌تر از
  حد خواندن، مسیر متن (زیرنویس آماده یا Whisper با نام مدل) و تعداد
  اصطلاحات واژه‌نامه، همه از روی زیرنویس واقعی همان کار حساب می‌شود
  و در `report.txt` و نتیجه بات و وب نمایش داده می‌شود.

## شروع سریع

به Python نسخه 3.10 به بالا، ffmpeg و وابستگی‌های پروژه نیاز داری:

```bash
pip install -e ".[bot,web,translate]"
cp .env.example .env
```

### خط فرمان

```bash
subfa lecture.mp4 --target fa --burn -o out/
subfa https://www.youtube.com/watch?v=VIDEO_ID --target fa --burn
subfa lesson.mkv --glossary programming --bilingual -o out/
```

### بات تلگرام

```bash
BOT_TOKEN=توکن-بات python -m bot.bot
```

یک ویدیو، فایل صوتی یا سند بفرست، یا لینک ویدیو را پیست کن. زبان
زیرنویس را با دکمه‌ها انتخاب کن؛ بات فایل‌های زیرنویس را می‌فرستد و
نسخه‌های کاری خودش را پاک می‌کند.

توجه: API عمومی بات تلگرام دانلود بات‌ها را به 20 مگابایت و آپلود را
به 50 مگابایت محدود می‌کند. برای فایل‌های بزرگ‌تر یک Bot API سرور
محلی اجرا کن. SubFa سقف واقعی را صادقانه اعلام می‌کند.

### صفحه وب

```bash
uvicorn web.app:app --host 0.0.0.0 --port 8000
```

صفحه را باز کن، فایل را رها کن یا لینک را بچسبان، و وقتی کار تمام
شد فایل‌ها را دانلود کن. فایل‌های هر کار یک ساعت بعد از اتمام خودکار
پاک می‌شوند.

### داکر

```bash
docker compose up web
docker compose up bot
```

با `--build-arg BUNDLE_MODELS=1` مدل‌های گفتار هنگام ساخت ایمیج
دانلود و داخل ایمیج گذاشته می‌شوند تا کانتینر موقع اجرا هیچ
دانلودی لازم نداشته باشد.

## اجرای کاملا آفلاین (مناسب ایران)

تنها دانلودهایی که SubFa لازم دارد مدل‌های گفتار و ترجمه‌اند و
فقط یک بار انجام می‌شوند:

```bash
subfa download-models
```

این دستور مدل faster-whisper، مدل فارسی فاین‌تیون‌شده و (وقتی
مترجم Argos است) بسته‌های ترجمه Argos را در یک پوشه کش ذخیره
می‌کند (`SUBFA_MODEL_CACHE`، پیش‌فرض
`~/.cache/subfa/models`). بعد از آن:

- پوشه را به هر ماشینی کپی کن، یا روی همان سرور نگهش دار.
- با `HF_HUB_OFFLINE=1` و بدون هیچ اینترنتی اجرا کن؛ پیاده‌سازی
  و ترجمه صددرصد لوکال‌اند.

آینه‌ها: دانلودها با ابزارهای Hugging Face انجام می‌شوند که به
متغیر محیطی `HF_ENDPOINT` احترام می‌گذارند. اگر هاب اصلی از
شبکه‌ات کند یا غیرقابل دسترس بود، قبل از اجرای
`download-models` مقدار `HF_ENDPOINT` را روی یک آینه بگذار.
برای سرورهای داخل ایران مطمئن‌ترین راه، مدل‌های داخل ایمیج
داکر است (`BUNDLE_MODELS=1`): یک بار هر جا که شبکه کار می‌کند
ایمیج را بساز و همان را جابه‌جا کن.

## لینک ویدیو و مسئولیت تو

دانلود لینک با [yt-dlp](https://github.com/yt-dlp/yt-dlp) انجام می‌شود.
دو سقف صادقانه وجود دارد که در فایل `.env` قابل تنظیم‌اند:

- `SUBFA_MAX_DURATION_MIN` با پیش‌فرض 60 دقیقه و `SUBFA_MAX_DOWNLOAD_MB`
  با پیش‌فرض 500 مگابایت. دانلودها به‌صورت پیش‌فرض روی کیفیت 720p
  سقف دارند، چون زیرنویس‌سازی به 4K نیاز ندارد.
- فقط محتوایی را دانلود یا زیرنویس کن که حق استفاده از آن را داری:
  ویدیوهای خودت، آثار عمومی، یا محتوایی که اجازه‌اش را گرفته‌ای.
  SubFa ابزار زیرنویس‌سازی است، نه راه دور زدن حقوق دیگران.

## حریم خصوصی

فایل‌ها به‌صورت محلی، در یک پوشه موقت پردازش و در پایان کار پاک
می‌شوند. فایل‌های دانلودشده از لینک هم همراه کار پاک می‌شوند. هیچ
چیزی به سرویس ابری پیاده‌سازی یا ترجمه فرستاده نمی‌شود: تشخیص گفتار
روی دستگاه خودت اجرا می‌شود و Argos Translate آفلاین کار می‌کند.

## ظاهر زیرنویس فارسی

زیرنویس چسبیده روی ویدیو با قالب ASS و از طریق libass ساخته می‌شود
و فونت پیش‌فرض آن **وزیرمتن** است. libass الگوریتم دوسویه یونیکد را
اعمال می‌کند، پس خط‌های فارسی درست راست‌به‌چپ رندر می‌شوند. وزیرمتن
را نصب کن تا ظاهر در نظر گرفته‌شده را ببینی (تصویر داکر تلاش می‌کند
بسته `fonts-vazirmatn` را نصب کند)؛ بدون آن، libass از یک فونت
سیستمی استفاده می‌کند و زیرنویس همچنان کار می‌کند، فقط ساده‌تر دیده
می‌شود. با `SUBFA_FONT` می‌توانی فونت دیگری انتخاب کنی.

## واژه‌نامه‌ها

واژه‌نامه یک فایل JSON در پوشه `glossaries/` است که هر اصطلاح را به
ترجمه دقیق مورد قبول جامعه وصل می‌کند:

```json
{ "programming": "برنامه‌نویسی", "bug": "باگ" }
```

اضافه کردن یا بهتر کردن یک واژه‌نامه ساده‌ترین راه مشارکت در SubFa
است: یک فایل، بدون کد. راهنما در [CONTRIBUTING.md](CONTRIBUTING.md).
